## A storefront with more than one perspective.

Mingo Shoes is an academic web project exploring the interfaces behind an online shoe store, from browsing products to reviewing a cart and entering checkout details.

The project also includes administration layouts for managing products, customers, and orders.

This repository brings together interface screenshots and front-end source code. The screens demonstrate the intended experience; they do not imply a production commerce service.

<br>

## What to look for

**Visual hierarchy across different tasks.**  
Compare how the storefront, product page, cart, and administration screens organize information.

**Continuity between pages.**  
Follow the shopping sequence and examine how navigation, recurring elements, and page structure connect the experience.

**The relationship between layout and behavior.**  
Read the markup and styles alongside the JavaScript to distinguish the visual interface from the interactions implemented in code.

<details>
<summary><strong>Inspecting the project locally</strong></summary>

<br>

Keep the repository structure intact: pages in `Source Code` reference supporting files elsewhere in the repository.

One way to inspect the project is to serve the repository root with a local static server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/Source%20Code/index.html
```

This is a suggested inspection method. A fresh browser run has not yet been verified for this documentation update.

Some assets or libraries may depend on external services. Check browser errors and file paths if a resource does not load.

</details>
